# assets/

Canonical brand and portfolio assets. The rules for using them (voice, writing, visual identity) live in [docs/06-brand/brand-system.md](../docs/06-brand/brand-system.md).

- `branding/`: canonical logo files (`logo-full.png`, `logo-mark.png`). App `public/` folders carry deploy copies; when a logo changes, this folder updates first and the copies follow.

New assets: descriptive kebab-case names, this folder first, then copy where needed.
