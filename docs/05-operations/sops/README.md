# Standard Operating Procedures

SOPs are step-by-step procedures for recurring operational work. If the operator does something for the third time, it becomes an SOP here. Agents automate SOPs; a process that is not written down cannot be automated.

## SOP conventions

- Numbered steps, each starting with a verb, each verifiable ("you should now see X").
- Name the exact tool, URL, or file for every step; no "somewhere in settings".
- An SOP that drifted from reality is a bug: fix it the moment you notice, in the same working session.
