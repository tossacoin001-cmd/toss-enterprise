# 07. Clients

This section owns non-code client records: one folder per client, holding scope, deliverables, and history. Status: Planned, empty. This fulfils the client-records home that ADR-0008 moved here from the old planned top-level `clients/`.

PII rules apply: minimum necessary data, nothing sensitive an agent does not need ([docs/03-ai/ai-operating-system.md](../../docs/03-ai/ai-operating-system.md)).
