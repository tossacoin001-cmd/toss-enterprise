# Corpora

This folder owns curated corpora: machine-usable knowledge bundles built from the sources in [../sources.md](../sources.md). Status: Planned, none exist.

Format when the first corpus lands: one folder per corpus with a `manifest.md` (what it contains, which sources, when generated, which docs it cites). Generated embedding artifacts are not committed; the pipeline must be re-runnable from scratch ([architecture/04-knowledge-brain.md](../../architecture/04-knowledge-brain.md)).
